The Ising model

Each pixel is a tiny magnet pointing up (light) or down (dark). Each one prefers to match its neighbours; heat makes them flip at random.

Temperature T
0.5Tc ≈ 2.274
Magnetization |m|
—

Energy H = −J Σ⟨i,j⟩ sisj with spins si = ±1 on a 160×160 torus, with J = 1 and Boltzmann's constant kB = 1, updated by Metropolis dynamics. The run starts with all spins up. |m| is the absolute value of the average spin. The critical temperature of the 2D model is Tc = 2/ln(1+√2) ≈ 2.269. The melt pond model in demo 4 is a variant: temperature zero, very strong coupling (J → ∞), and a random field at each site.

每个像素是一个小磁针，朝上（浅色）或朝下（深色），都想和邻居方向一致；温度会让它们随机乱翻。这里取 J = 1、玻尔兹曼常数 kB = 1，用 Metropolis 方法更新，开始时所有磁针都朝上。|m| 是所有磁针方向的平均值取绝对值。二维模型的临界温度约为 2.269。第 4 个融池模型是这个模型的变体：温度为零，邻居之间的作用非常强（J → ∞），每个格子再加上一个自己的随机偏好。
